# 📊 HR Analytics Dashboard | Power BI

## 📌 Overview

The HR Analytics Dashboard is an interactive Power BI project designed to help HR professionals monitor workforce performance, employee demographics, retention, and promotion insights. The dashboard transforms raw HR data into meaningful visualizations, enabling data-driven decision-making.

---

## 🚀 Features

- 📈 Employee Overview
  - Total Employees
  - Active Employees
  - Retrenched Employees
  - Employees Due for Promotion

- 👥 Workforce Demographics
  - Gender distribution
  - Job level distribution
  - Employee distance from workplace

- 📅 Service Analysis
  - Employees by years of service
  - Promotion eligibility analysis

- 📊 Interactive Visualizations
  - KPI Cards
  - Bar Charts
  - Donut Charts
  - Navigation buttons between report pages
  - Interactive filtering
